# 카히스토리 Hero 모션 프로토타입

`index.html`을 Chrome 또는 Edge로 열면 실행됩니다. 빌드·설치·인터넷 연결이 필요하지 않습니다. GSAP 3.13.0을 vendor에 포함했습니다. 제공된 이미지에 맞춰 만든 화면이며 실제 카히스토리 서비스 및 조회·결제에는 연결되지 않습니다.

## 동작

- 최초 로드마다 3초짜리 GSAP 타임라인 1회 실행, repeat: 0.
- 0–0.35 정지 / 0.35–0.90 접근 / 0.90–1.10 충격 / 1.10–1.55 반동 / 1.55–2.10 안정 / 2.10–2.70 정리 / 2.70–3.00 정지.
- 효과는 impact에서 표시. 충격선과 입자는 0.2초, 연기는 0.46초 후 사라집니다.
- 최종 차량 간 간격은 약 12 SVG 단위입니다. 화면 크기에 따라 일러스트와 이동거리 모두 함께 축소됩니다.
- 검색창, 문구, Hero, 방패에는 애니메이션 transform이 적용되지 않습니다.
- 운영체제의 동작 줄이기를 켜면 최종 상태를 바로 표시합니다. 실행 도중 켜도 즉시 종료합니다.
- 새로고침으로 다시 확인할 수 있습니다. 스크롤, 리사이즈, 탭 복귀로 재시작하지 않습니다.

## 파일 및 통합

- index.html: 시안 기반 미리보기 및 인라인 SVG.
- style.css: 시안 레이아웃, 반응형 크기.
- script.js: CONFIG, 라벨이 있는 단일 GSAP 타임라인, 데모 입력 처리.
- assets/truck.svg, car.svg, impact.svg: 개별 재사용 가능한 SVG 원본.
- vendor/gsap.min.js: 공식 배포본. 상단 라이선스 안내 유지.

기존 페이지에 적용할 때 `.art` 내부 인라인 SVG, 해당 스타일, script.js의 모션 초기화 부분을 옮깁니다. SVG ID는 페이지에서 유일해야 합니다. 인라인 SVG는 별도 SVG 원본의 복사본이므로 원본을 변경하면 인라인 버전도 갱신해야 합니다. 원본 홈페이지 소스는 제공되지 않아 실제 서비스에 직접 반영한 상태는 아닙니다.

`CONFIG`에서 시간, 접근거리, 반동, 바운스 값을 조정할 수 있습니다. 접근거리 변경 시 차량 접점도 함께 확인하세요. 현재 360×220 viewBox에서 트럭 접점은 165.6+18=183.6, 승용차 접점은 200+1.7−18=183.7입니다. 트럭의 왼쪽 운전석 실루엣을 유지해 트럭 뒤쪽과 승용차 앞쪽이 가볍게 닿도록 구현했습니다.
